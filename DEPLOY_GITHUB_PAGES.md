# GitHub Pages deployment

1. Create a new GitHub repository, e.g. `meeting-recorder-web`.
2. Upload all files from this ZIP to the repository root.
3. GitHub → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder `/ (root)`.
6. Save.
7. GitHub will show an HTTPS site URL.
8. Open the HTTPS site in Edge/Chrome.
9. Allow microphone access when asked.

Because the site is served over HTTPS, browser microphone and screen-audio permissions can work.

If your company blocks GitHub Pages, use another approved HTTPS static host.
